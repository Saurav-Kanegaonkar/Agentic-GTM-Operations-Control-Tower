# Data Sources

This folder contains deterministic synthetic GTM operations data for a technical B2B infrastructure company. The data is generated by `scripts/score_operating_data.py` with random seed `42`.

The synthetic structure is modeled on common revenue operations systems:

- `accounts.csv`: named accounts with segment, territory, pipeline stage, forecast category, workload fit, data completeness, and account health.
- `agent_workflows.csv`: AI workflow candidates across pipeline creation, deal acceleration, forecasting, planning, customer growth, governance, and leadership cadence.
- `workflow_runs.csv`: weekly workflow adoption, acceptance, lift, and QA exception telemetry.
- `pipeline_snapshots.csv`: territory-level pipeline creation, stage progression, closed won value, forecast commit, velocity, and forecast risk.
- `territory_capacity.csv`: quota, account load, pipeline coverage, releasable admin hours, and planning recommendations.
- `data_quality_checks.csv`: source freshness, completeness, ownership, and launch blocker flags.
- `recommended_actions.csv`: action candidates tied to workflow owners and expected outcomes.

No row represents an actual company, customer, prospect, employee, or production system.
